# 🔋 Bottery

**A Python framework for building bots.**

[![Python Versions](https://img.shields.io/pypi/pyversions/bottery.svg)](https://pypi.org/project/bottery/)

Bottery is a Python framework that helps developers build and run bots. It provides command-line tools for creating new projects and starting bot applications.

## 📋 Requirements

Before installing Bottery, make sure you have:

- Python installed.
- `pip`, Python's package installer.
- A terminal or command-line interface.

Check your Python and pip versions:

```bash
python --version
python -m pip --version
```

## 📦 Installation

Install Bottery with pip:

```bash
python -m pip install bottery
```

After installation, check whether the command-line interface is available:

```bash
bottery --help
```

## 🚀 Getting Started

Follow these steps to create and run your first Bottery project.

### 1. Create a project

Run the following command to create a project named `librarybot`:

```bash
bottery startproject librarybot
```

### 2. Open the project directory

Navigate to the newly created project:

```bash
cd librarybot
```

### 3. Run the bot

Start the application from the project directory:

```bash
bottery run
```

**Note:** The commands and project structure may vary depending on the installed Bottery version. Consult the documentation if a command is unavailable.
